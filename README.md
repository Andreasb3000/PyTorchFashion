# Fashion-MNIST Classification Using PyTorch

## Project Overview

This project uses a fully connected neural network built with PyTorch to classify images from the Fashion-MNIST dataset.

The project focuses on three research questions:

1. How accurately can a basic PyTorch neural network classify Fashion-MNIST clothing images?
2. How does the number of neurons in the hidden layer affect classification accuracy and training time?
3. Which clothing categories are most frequently confused by the neural network?

The project compares models containing 32, 64, 128, and 256 hidden neurons. The best model is selected using validation accuracy and is then evaluated on the separate Fashion-MNIST test dataset.

## Required Libraries

The project uses Python 3 and the following libraries:

* NumPy
* pandas
* Matplotlib
* PyTorch

The EDA and testing files may also use standard Python libraries such as `pathlib` and `tempfile`.

The required packages can be installed with:

```bash
python -m pip install numpy pandas matplotlib torch
```

I developed the project using a Conda environment named `pytorchfashion`. A Conda environment is not required as long as the necessary Python libraries are installed.

## Dataset

This project uses the Fashion-MNIST dataset originally created by Zalando Research.

The data used by this project is stored in CSV format:

```text
data/fashion-mnist_train.csv
data/fashion-mnist_test.csv
```

The training file contains 60,000 images and the testing file contains 10,000 images.

Each image is 28 by 28 pixels, resulting in 784 pixel values per image. Each image also has a numerical label from 0 through 9 representing one of ten clothing categories.

The data files are not included directly in the GitHub repository because of their size. Before running the project, place both CSV files inside the `data` directory using the exact filenames shown above.

Fashion-MNIST information can be found at:

https://github.com/zalandoresearch/fashion-mnist

## Project Files

### `eda.py`

Performs the exploratory data analysis for the project.

This file:

* Loads the training and testing CSV files.
* Checks the structure and validity of the datasets.
* Checks for missing values.
* Calculates image-level statistics such as mean intensity, pixel standard deviation, and number of nonzero pixels.
* Calculates summaries for each clothing category.
* Creates the EDA visualizations.

### `modeling.py`

Contains the main PyTorch machine-learning functions used by the project.

This file:

* Converts the CSV data into PyTorch tensors.
* Normalizes pixel values from 0-255 to 0-1.
* Creates training, validation, and testing `DataLoader` objects.
* Defines the `FashionClassifier` neural-network class.
* Trains neural networks using cross-entropy loss and the Adam optimizer.
* Measures validation accuracy and training time.
* Generates test predictions.
* Creates the confusion matrix.
* Calculates classification accuracy for each clothing category.

### `main.py`

Runs the final machine-learning experiment.

This file:

* Loads the Fashion-MNIST data.
* Trains models with 32, 64, 128, and 256 hidden neurons.
* Uses the same model settings and training/validation split for each model.
* Records validation accuracy, training loss, and training time.
* Selects the best model based on validation accuracy.
* Evaluates the selected model on the official testing dataset.
* Creates the final result visualizations.
* Prints the main numerical results.

### `test_eda.py`

Contains tests for the functions used in `eda.py`.

The tests use small datasets with manually checkable values to verify data loading, validation, summary calculations, missing-value calculations, and visualization output.

### `test_modeling.py`

Contains tests for important functions in `modeling.py`, including data conversion, accuracy calculations, confusion-matrix creation, and per-category accuracy calculations.

## Running the Project

### 1. Open the project directory

In a terminal, navigate to the repository:

```bash
cd PyTorchFashion-1
```

### 2. Activate the Python environment

If using the Conda environment used during development:

```bash
conda activate pytorchfashion
```

Make sure to use `python` rather than the system `/usr/bin/python3` if the Conda environment is active.

You can confirm which Python is being used with:

```bash
which python
```

### 3. Install the required libraries

```bash
python -m pip install numpy pandas matplotlib torch
```

### 4. Add the Fashion-MNIST CSV files

Make sure the following files exist:

```text
data/fashion-mnist_train.csv
data/fashion-mnist_test.csv
```

### 5. Run the exploratory data analysis

```bash
python eda.py
```

This generates the EDA results and visualizations.

### 6. Run the final neural-network experiment

```bash
python main.py
```

The program trains four neural networks with different hidden-layer sizes.

For each model, the terminal will display the training loss and validation accuracy after each epoch.

After all models finish training, the program will print:

* Validation accuracy for each hidden-layer size.
* Training time for each hidden-layer size.
* The best hidden-layer size.
* Final test accuracy.
* Accuracy for each clothing category.

## Generated Results

Running `main.py` creates the following files inside the `results` directory:

```text
model_comparison.png
loss_curves.png
confusion_matrix.png
per_category_accuracy.png
misclassified_examples.png
```

`model_comparison.png` compares validation accuracy and training time between the four hidden-layer sizes.

`loss_curves.png` shows how training loss changes across epochs for each model.

`confusion_matrix.png` shows the relationship between the true clothing categories and the model's predictions.

`per_category_accuracy.png` compares test accuracy across the ten Fashion-MNIST categories.

`misclassified_examples.png` displays test images that the selected model classified incorrectly along with their actual and predicted labels.

The EDA program also produces visualizations describing the original Fashion-MNIST dataset.

## Reproducibility

The project uses a fixed random seed during the training/validation split and model initialization so that the four neural-network configurations can be compared using the same experimental conditions.

The official Fashion-MNIST testing dataset is kept separate from model training and model selection. The best model is chosen using validation accuracy before its final performance is measured on the testing dataset.
